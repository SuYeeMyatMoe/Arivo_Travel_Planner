Ari, Arivo Guide's mascot, as transparent 1024px renders: four hero poses (idle, excited, thinking, pointing), a four-view turnaround, and the talking sprite sheet (4×4 frames, 256px cells) that drives the 64px Guide FAB. Use the poses on ink or paper; never recolour them, crop the hat, or add a drop shadow (Ari floats on shadow-raised only as the FAB). The source 3D model is `assets/mascot/ari_explorer.glb` in the Arivo repo. Derived from "Miibot 3D Model" by itsmejhade, CC BY 4.0.
